# Ariya Monitor Lite（軽量版）

日産アリアのOBD2ポートから、バッテリーの状態などを読み取って表示するAndroidアプリの **軽量版** です。
**個人が作った非公式アプリです。日産自動車とは関係ありません。**

**Android 5.0以上** で動きます。通常版（Android 8.0以上）が入らない端末や、通常版が重く感じる端末（古いFireタブレットなど）向けです。
Android 8.0以上で快適に動く端末なら、[通常版](https://github.com/kojipa/ariyamonitor-releases) がおすすめです。

> ⚠️ **試験公開中です。** 作者の車（1台）でしか動作を確かめていません。特に **Android 5〜7の端末では、まだ動作を確認できていません。** 動いた・動かなかった、どちらの報告も歓迎します（端末名とAndroidのバージョンも教えてください）。

## ダウンロード

👉 **[最新版のページ（Releases）](../../releases/latest)** を開き、`ariyamonitor-lite-x.y.z.apk` をダウンロードしてください。

## できること

- **ホーム**：SOC（充電率）と車の画像を表示します。バッファを含まない実SOCを大きく、メーターのSOCを小さく表示します。状態（充電中・走行中・回生・待機）は色の変化で表します。
- **一覧**：バッテリー最高・最低温度、冷却水温、パック電圧、電流、実SOC・メーターSOC、車速、BMS残エネルギー、充電電力を表示します。
- **直近15分のグラフ**：選んだ項目の変化を、目盛り付きのグラフで表示します。
- **自動接続**：アプリを起動すると、OBD2アダプターに自動でつながります。車の電源を切って10分たつと、読み取りを自動で止めます。
- 画面は縦向き・横向きのどちらでも使えます。アプリのサイズは約1MBです。

電流・充電電力は **「参考値」** です。作者の車でも精度を検証しきれていないので、目安として見てください。

## 通常版との違い

| | 通常版 | Lite版 |
|---|---|---|
| 対応Android | 8.0以上 | **5.0以上** |
| ホームの演出 | 光が流れるアニメーション | 静止画＋色の変化（軽い） |
| デモモード | あり | なし |
| 更新のお知らせ | あり（1日1回確認） | **なし**（このページで確認してください） |
| インターネット通信 | 更新確認のみ | **一切なし** |

通常版とLite版は別のアプリなので、同じ端末に両方入れることもできます。

## 安全について

- **車には読み取りのコマンドしか送りません。** 書き込み、ECUのリセット、故障コードの消去などは、機能として入っていません。
- **インターネットに一切接続しません。** 車両のデータを外部に送ることはなく、アカウント登録もありません。
- 位置情報は使いません。

## 必要なもの

| もの | 条件 |
|---|---|
| 車 | 日産アリア |
| Android | 5.0以上（スマートフォン、タブレット、車載のAndroid機器など） |
| OBD2アダプター | **Bluetooth（クラシック／SPP）** 接続の **ELM327互換** アダプター |

- Bluetooth Low Energy（BLE）専用のアダプターや、Wi-Fi接続のアダプターには対応していません。
- アダプターは、先にAndroidの「設定」→「Bluetooth」でペアリングしておいてください（PINはたいてい `1234` か `0000` です）。

## インストール方法

1. 端末のブラウザで、最新版のページからAPKをダウンロードします。
2. ダウンロードしたファイルを開きます。
3. 提供元不明のアプリのインストールを許可します。
   - **Android 8.0以上**：「この提供元のアプリを許可しますか」と出たら **許可** して戻ります。
   - **Android 5〜7**：「設定」→「セキュリティ」→ **「提供元不明のアプリ」** をオンにします。
   - **Fireタブレット**：「設定」→「セキュリティとプライバシー」→ **「不明ソースからのアプリ」** で、使っているブラウザ（Silkなど）を許可します。
4. **Google Play プロテクト**の警告が出ることがあります。Google Playを通していないアプリのため、表示されることがあります。「スキャンせずにインストール」または「詳細」→「このままインストール」で進めてください。

## 使い方

1. 車の電源を入れて、OBD2アダプターを差し込みます。
2. アプリを起動し、注意書きを読んで「同意して開始」を押します。
3. 「設定」の **Bluetooth接続先** で、ペアリング済みのOBD2アダプターを選びます。
4. 「接続開始」を押すと、数秒〜十数秒でホームに値が表示されます（次回からは起動時に自動で接続します）。

うまくつながらないときは、アダプターを抜き差しする、車の電源を入れ直す、他のOBDアプリ（Car Scannerなど）を終了する、の順に試してください。Bluetoothは同時に1つのアプリしか接続できません。

## アップデート

Lite版はインターネットに接続しないため、アプリ内に更新のお知らせは出ません。ときどきこのページを確認し、新しい版があればAPKをダウンロードして上書きインストールしてください。設定は引き継がれます。
